# RGB-D 本机建模工作台

## 启动

在项目目录运行：

```sh
./start_workbench.sh
```

访问 http://127.0.0.1:8765 。保持启动终端运行；Ctrl+C 安全停止服务和当前计算进程，下次启动后可重试中断任务。仅启动一个服务进程，不使用 uvicorn --workers 多进程模式。

当前已安装依赖并构建前端。代码修改后运行 `sh scripts/build_frontend.sh` 再启动。脚本优先使用项目内 .runtime/node/bin/node，缺失时使用系统 Node。可通过 `SLAM_NODE=/绝对路径/node` 指定其他 Node 22+。

新环境：创建 Python 虚拟环境（本机为 Python 3.14），安装 `requirements.web.lock.txt`；前端在 frontend 目录用 pnpm 安装锁定依赖（必要时批准官方 esbuild 构建脚本），再运行构建脚本。依赖安装需要网络，已构建工作台运行不需要网络。前端资源打包在本地，没有 CDN。

## 上传与建模

1. 点击“新建”，选择完整拍摄文件夹，或上传 ZIP。拖放只支持 ZIP。
2. 每组用正整数文件夹名，例如1、2、3；每组需包含 image.jpg、calibration.json、depth.json、depth.f32、confidence.u8。批次可带 order.json 与 README.txt；系统忽略 .DS_Store。
3. 支持当前 Captures4 的 ARKit schema_version=2、原生方向1、米制Z深度、float32小端布局。JPEG本身不是深度输入。其他RGB-D导出格式不能直接套用。
4. 选择项目名；通常10–200组，3–9组须勾选小批量诊断。
5. 点击“上传并自动建模”。上传完成后自动校验并排队，校验失败报告具体组和原因。正常显示阶段而非伪造百分比。固定接受中+高置信度，低置信度排除，融合间距5mm、清晰度预警45。
6. 结果页可旋转/缩放点云，切换主点云与额外视角支持点云，查看RGB/深度/置信度，相机位置及独立模型。取消及重试保留旧版本。

## 测距与导出

点击“两点测距”，依次点击点云上两个实际点。显示的是端点欧氏距离，米制尺度来自LiDAR。点击新点开始下一次测量。观察遮挡与点大小，避免选中背景；此功能不是自动屏幕边缘检测，也没有独立精度保证。

导出PLY、相机JSON和完整结果包。完整包包括输入数据、配置、处理脚本快照、依赖锁定、日志、深度检查、原生SfM模型、融合结果及报告。不将数据库中的绝对系统路径用作任意下载路径。

当前不提供外部尺量定尺度的网页表单：LiDAR结果本身已为米制，不能用模型自产生的估计尺寸重复校准。尚未实现ICP、RGB-D联合位姿优化、网格重建、自动物体尺寸识别。更大点云的分块LOD、断点续传和多用户远程部署留待后续；当前预览先加载最多约5万点，再加载完整PLY。

## 数据与接口

- frontend/：React、TypeScript、Three.js；编译后由FastAPI同源提供。
- backend/app.py：API、SQLite状态、单任务队列与独立计算子进程。
- scripts/：复用的图像、深度、SfM和融合计算脚本。
- data/workbench/state.sqlite3：项目和任务；data/workbench/jobs/{任务id}/：每次运行产物。
- 服务端存储可用环境变量 SLAM_STORAGE 改到另一个目录。
- API文档：http://127.0.0.1:8765/docs 。写入请求需要 `x-workbench: 1`，仅接受本机Host/Origin。

主要接口：POST /api/projects；POST /api/projects/{id}/uploads；PUT /api/uploads/{id}/file；POST /api/uploads/{id}/zip；POST /api/uploads/{id}/complete；GET /api/jobs/{id}；POST /api/jobs/{id}/cancel；POST /api/jobs/{id}/retry；GET /api/jobs/{id}/photos；GET /api/jobs/{id}/artifacts/{path}；GET /api/jobs/{id}/download。

## 验证

```sh
.venv/bin/python -m unittest discover -s tests -v
sh scripts/build_frontend.sh
```

基础测试可直接运行；两项 Captures4 数据测试需要项目内 Captures4 文件夹，或通过 SLAM_TEST_CAPTURES 指定测试数据路径；未提供时跳过。这仅是测试数据，不是运行依赖。
